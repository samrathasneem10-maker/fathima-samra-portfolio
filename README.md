# 🚀 Getting Started

## 📋 Prerequisites

No additional software is required to view the portfolio.

A modern web browser such as:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

is recommended.

## 📥 Clone the Repository

```bash
git clone https://github.com/samrathasneem10-maker.github.io/fathima-samra-portfolio/.git
```

## 📂 Open the Project

```bash
cd fathima-samra-portfolio
```

Then open:

```text
index.html
```

in your web browser.
